Remote MCP & AI Client Integration Guide

Connect your AI coding assistants directly to this cloud repository via Server-Sent Events (SSE).

Cursor IDE Setup

Open Cursor Settings → Features → MCP, click "Add New MCP Server":

  • Type: SSE
  • Name: HTMLDropHub
  • Server URL: https://<your-domain>/sse?token=<YOUR_TOKEN>

// In Cursor Chat, simply instruct:

"Build a single-file tax calculator and deploy it via drop_html tool."
Claude Desktop Config

Add this entry inside your claude_desktop_config.json: 

{
  "mcpServers": {
    "htmldrophub": {
      "url": "https://<your-domain>/sse?token=<TOKEN>"
    }
  }
}
cURL Direct API Push

Send raw HTML or JSON payload directly from any terminal or CI/CD script: 

curl -X POST "http://localhost:3000/api/drop" \
  -H "Authorization: Bearer <YOUR_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "demo.html",
    "title": "Quick Demo",
    "content": "<h1>Hello World</h1>"
  }'
Cloudflare Tunnel & Zero Trust

Run safely behind Cloudflare without opening any firewall ports:

  • In Cloudflare Zero Trust, configure an Access Application for your domain.
  • Add a Bypass Rule for path /sse* and /messages* or verify headers.
  • When accessing /admin, Cloudflare automatically passes Cf-Access-Authenticated-User-Email header to log you in automatically!
